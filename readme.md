# UNILIB - Sistema de Gestión Bibliotecaria

Proyecto desarrollado para la asignatura **Ingeniería de Software (RQY1102)** de **Duoc UC**.

## Descripción

**UNILIB** es un Sistema de Gestión Bibliotecaria diseñado para administrar:

* Préstamos y devoluciones de libros
* Gestión de usuarios
* Catálogo bibliográfico
* Generación de reportes

Además, el repositorio incluye un **prototipo web funcional** desarrollado como una página estática para representar la interfaz inicial del sistema.

## Estructura del repositorio

* **EA01/**: Entregables de la Experiencia de Aprendizaje 01
* **EA02/**: Entregables de la Experiencia de Aprendizaje 02
* **EA03/**: Entregables de la Experiencia de Aprendizaje 03
* **EFT/**: Entregables de la Evaluación Final
* **docs/**: Prototipo web estático (HTML, CSS y JavaScript)

## Prototipo

El prototipo web fue desarrollado en **HTML**, utilizando **CSS** para el diseño y estilos visuales, y **JavaScript** para implementar la lógica e interactividad de la interfaz. El prototipo puede visualizarse en:

https://solidusstrange.github.io/RQY1102-UNILIB/index.html
